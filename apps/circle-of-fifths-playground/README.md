# Circle of Fifths Playground

Interactive browser UI for the options exposed by `@circle-of-fifths/svg`.
The preview updates immediately, the current settings are represented in the
URL, and the rendered self-contained SVG can be downloaded.

```console
pnpm dev:circle-of-fifths
```

Open <http://localhost:17382>.

Checks for this app:

```console
pnpm --dir apps/circle-of-fifths-playground test
pnpm --dir apps/circle-of-fifths-playground check
pnpm --dir apps/circle-of-fifths-playground build
```
