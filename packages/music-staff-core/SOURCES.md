# Staff notation references

Staff key signatures use the shared Finale Maestro accidental outlines and
renderer documented in [`music-notation`](../music-notation/SOURCES.md). This
includes full-size staff notation, Circle of Fifths, and movable-do settings.
The clef outlines use the same source font and are described there as well.

The [Wikipedia Key signature article](https://en.wikipedia.org/wiki/Key_signature)
and its [F-sharp major](https://commons.wikimedia.org/wiki/File:Key_Signature_F-sharp_major.jpg)
and [B-flat major](https://commons.wikimedia.org/wiki/File:Key_Signature_B-flat_major.jpg) JPEG references
were used only to check spacing: 48 pixels for a sharp and 42 pixels for a flat
per 42.75-pixel staff space. No image contours were traced or retained. These
are font outlines, not a claim of exact reproduction of the Wikipedia raster.
